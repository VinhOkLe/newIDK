CSS Selector Cheat Sheet

“Query” trong CSS chính là selector: câu truy vấn để chọn đúng phần tử HTML rồi style cho nó. Trọng tâm là dạng .class, kèm #id, thẻ, thuộc tính, combinator và pseudo-class. Cùng một cú pháp này cũng dùng trong JavaScript: document.querySelector('.card').

🎯 .class = chọn theo class #id = chọn theo id duy nhất div p = chọn theo quan hệ :hover = chọn theo trạng thái
HTML mẫu dùng xuyên suốt file này

Đọc HTML trước, rồi mới hiểu selector chọn cái nào

<div class="card featured">
  <h2 class="title">Tiêu đề</h2>
  <p class="desc">Mô tả sản phẩm</p>
  <button class="btn primary">Mua ngay</button>
</div>

<ul class="menu">
  <li>Trang chủ</li>
  <li>Sản phẩm</li>
  <li>Liên hệ</li>
</ul>

Quy ước đọc:

  • class="card featured" nghĩa là phần tử đó có 2 class: card và featured.
  • class="btn primary" tương tự: có cả btn và primary.
  • Trong CSS, dấu chấm . đi trước tên class, dấu thăng # đi trước id. Viết card không có dấu chấm là chọn thẻ <card> — thẻ này không tồn tại.
Cách đọc selector: đọc từ phải sang trái. .card .title = “phần tử có class title nằm trong phần tử có class card”.
1 — Cơ bản nhất

Chọn theo thẻ, .class, #id

SelectorChọn cái nào?Ví dụ
*Mọi phần tử* { margin: 0; }
pMọi thẻ <p>p { line-height: 1.6; }
.cardMọi phần tử có class card.card { border: 1px solid #ddd; }
#headerPhần tử có id header (duy nhất)#header { position: sticky; }
div.cardThẻ <div> có class carddiv.card { ... }
.btn.primaryPhần tử có cả 2 class btn và primary.btn.primary { background: purple; }
.card, .boxCả class card và class box (dấu phẩy = “hoặc”).card, .box { padding: 16px; }
Phân biệt quan trọng nhất:
.card.featured (không khoảng trắng) = 1 phần tử vừa có class card vừa có class featured.
.card .featured (có khoảng trắng) = phần tử class featured nằm bên trong phần tử class card.
2 — Quan hệ cha / con / anh em

Combinator: 4 dấu nối

SelectorTênChọn cái nào?
.card pDescendant (khoảng trắng)Mọi <p> nằm trong .card, sâu bao nhiêu cũng được
.card > pChild (>)Chỉ <p> là con trực tiếp của .card
h2 + pAdjacent (+)<p> đứng ngay sau <h2>, cùng cha
h2 ~ pGeneral sibling (~)Mọi <p> đứng sau <h2>, cùng cha
/* HTML: .menu > li > a */
.menu li { ... }        /* mọi li trong menu, kể cả menu con */
.menu > li { ... }      /* chỉ li cấp 1, không ăn menu con */
.menu > li > a { ... }  /* link của li cấp 1 */

/* Dùng + rất hay cho form: label ngay sau input */
input:checked + label { font-weight: bold; }
Mẹo thực tế: menu đa cấp thì dùng > để style cấp 1 không bị “dính” sang cấp con. List lồng nhau mà dùng khoảng trắng thì cấp con cũng bị ăn theo.

Attribute selector: [ ... ]

SelectorChọn cái nào?

[type="text"]type đúng bằng text
[href^="https"]href bắt đầu bằng https

input[type="text"],
input[type="email"] { border: 1px solid #ccc; }

4 — Theo trạng thái & vị trí

Pseudo-class: :một-dấu-hai-chấm

NhómSelector hay dùng
Chuột / bàn phím:hover, :active, :focus, :focus-visible, :visited
Form:checked, :disabled, :enabled, :required, :valid, :invalid, :placeholder-shown
Vị trí trong cha:first-child, :last-child, :only-child, :nth-child(n), :nth-last-child(n)
Vị trí theo loại thẻ:first-of-type, :last-of-type, :nth-of-type(n)
Khác:empty (không có con gì), :root (thẻ <html>), :not(...) (phủ định)
/* Vị trí: n bắt đầu từ 1, không phải 0 */
.menu li:first-child { ... }   /* li đầu tiên */
.menu li:last-child  { ... }   /* li cuối cùng */
.menu li:nth-child(2)     { ... }  /* li thứ 2 */
.menu li:nth-child(odd)   { ... }  /* li lẻ: 1, 3, 5... */
.menu li:nth-child(even)  { ... }  /* li chẵn: 2, 4, 6... */
.menu li:nth-child(3n)    { ... }  /* li 3, 6, 9... */
.menu li:nth-child(3n+1)  { ... }  /* li 1, 4, 7... */

/* Phủ định: mọi nút trừ nút chính */
.btn:not(.primary) { background: #eee; }
:first-child vs :first-of-type: p:first-child chỉ đúng khi <p> đó là con đầu tiên của cha. Nếu con đầu tiên là <h2> thì p:first-child không chọn gì cả — lúc đó dùng p:first-of-type.
5 — Phần “ảo” của phần tử

Pseudo-element: ::hai-dấu-hai-chấm

SelectorTác dụng
::before / ::afterChèn nội dung ảo trước / sau phần tử — bắt buộc có content: ""
::first-lineDòng đầu tiên của đoạn văn
::first-letterChữ cái đầu tiên (drop cap)
::markerDấu đầu dòng của <li>
::selectionPhần text người dùng bôi đen
::placeholderText placeholder trong input
.btn::before { content: "🛒 "; }
.price::after { content: " VNĐ"; }
.desc::first-letter {
  font-size: 2em; font-weight: bold;
}
::selection { background: yellow; }
input::placeholder { color: #999; }

Phân biệt: :hover là trạng thái thật (1 dấu hai chấm), ::before là phần tử ảo (2 dấu hai chấm). Trình duyệt cũ vẫn hiểu :before 1 dấu, nhưng chuẩn mới nên viết 2 dấu.

6 — Nâng cao, gọn code

:is() :where() :has()

/* :is() — gộp nhiều selector, khỏi lặp lại */
:is(h1, h2, h3) { margin: 0; }
/* thay cho: h1, h2, h3 { margin: 0; } */
.card :is(.title, .desc) { color: #333; }

/* :where() — giống :is() nhưng độ ưu tiên = 0,
   nên dễ bị ghi đè, hợp làm style mặc định */
:where(.card, .box) p { margin: 0; }

/* :has() — chọn CHA dựa vào CON (selector ngược) */
.card:has(img) { padding: 0; }          /* card nào có ảnh */
.card:has(> .badge) { border-color: red; }
label:has(input:checked) { font-weight: bold; }
a:has(> img) { display: inline-block; }
:has() là thứ trước đây CSS không làm được (phải nhờ JavaScript). Trình duyệt hiện đại đều hỗ trợ. Nếu cần hỗ trợ trình duyệt rất cũ thì vẫn phải dùng JS.
7 — Khi 2 selector cùng chọn 1 phần tử, ai thắng?

Specificity: độ ưu tiên (không phải “viết sau thắng”)

Tính điểm: inline style = 1000, #id = 100, .class / [thuộc tính] / :pseudo-class = 10, thẻ / ::pseudo-element = 1, * = 0. Điểm cao hơn thắng, bất kể viết trước hay sau. Bằng điểm thì rule viết sau thắng.

SelectorCách tínhĐiểm
p1 thẻ1
.card p1 class + 1 thẻ11
.card .title2 class20
#header .menu a1 id + 1 class + 1 thẻ111
style="..." (inline)—1000
!important—Thắng hết (trừ !important khác)
❌ Tránh: càng lồng sâu càng khó ghi đè sau này.
#page .wrap .content .card .title { ... }
→ điểm cao, sau này muốn đổi màu phải viết selector còn dài hơn.
✅ Nên: class ngắn, đủ rõ nghĩa.
.card-title { ... }
→ điểm thấp, dễ ghi đè bằng 1 class khác, dễ tái dùng.

Quy tắc: dùng !important chỉ khi thật sự bí, vì nó phá thứ tự ưu tiên và gây khó debug. Ưu tiên đặt tên class rõ nghĩa (kiểu BEM: .card__title, .card--featured) thay vì lồng selector sâu.

9 — Cùng cú pháp, dùng trong JavaScript

document.querySelector()

“Query” còn là tên hàm JS lấy phần tử — và nó nhận đúng selector CSS này.

// Lấy phần tử ĐẦU TIÊN khớp selector
document.querySelector('.card');
document.querySelector('#header');
document.querySelector('.menu > li:first-child');

// Lấy TẤT CẢ phần tử khớp selector
document.querySelectorAll('.btn.primary');
document.querySelectorAll('input[type="text"]');
Nhớ: querySelector('.card') có dấu chấm. Viết querySelector('card') là tìm thẻ <card> → trả về null.
10 — Lỗi hay gặp

Checklist khi style “không ăn”

  • Quên dấu chấm: viết card { } thay vì .card { }.
  • Nhầm khoảng trắng: .card .title ≠ .card.title (xem mục 1).
  • Sai tên class: class phân biệt hoa thường — .Card ≠ .card.
  • Trùng id: id phải duy nhất trong trang. Cần style nhiều phần tử → dùng class.
  • Bị rule khác đè: kiểm tra specificity (mục 7) và thứ tự file CSS — không vội thêm !important.
  • Thiếu class trong HTML: CSS viết đúng nhưng HTML chưa gắn class đó.
  • :nth-child đếm từ 1, không phải từ 0 như mảng trong JS.
Cách debug nhanh: mở DevTools (F12) → tab Elements → nhìn xem phần tử có đúng class không, rule nào bị gạch ngang (bị đè) và rule nào thắng.
Nhớ nhanh: . = class, # = id, khoảng trắng = nằm trong, > = con trực tiếp, + = ngay sau, ~ = sau đó, : = trạng thái, :: = phần ảo.
